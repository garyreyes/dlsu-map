# DLSU 3D Campus Navigator

A free, offline-first 3D map of De La Salle University (Manila) that routes you to any room, outdoors and floor by
floor indoors. Runs in the phone browser on iPhone and Android.

> **Status:** initial planning, under review. No app code yet. v1 will be the outdoor campus; interiors follow,
> starting with Andrew.
